# ADR-0002. Язык серверной части: Go

| Атрибут | Значение |
| --- | --- |
| Назначение | Выбрать язык реализации `sentinel-server` |
| Версия | 1 |
| Дата | 2026-11-10 |
| Статус | Accepted |
| Решение владельца | D-02 (DECISION_LOG.md), согласовано 2026-11-10 |
| Связанные требования | CLAUDE.md §6; ARCH-0001 §8 |
| Затронутые компоненты | Management Server, компилятор политик, Incident Management, Integrations |

## Контекст

Серверу нужны gRPC с mTLS для агентов, REST API для консоли и внешних систем, интеграции LDAP/AD, OIDC и SAML, работа с PostgreSQL, поставка в виде пакетов RPM/DEB и OCI-образов для изолированных сред. Разбор недоверенного содержимого файлов на сервере выполняет не Go-код, а общее Rust-ядро (ADR-0003).

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Go | Статический бинарь без рантайма; зрелые библиотеки gRPC, LDAP, OIDC; быстрая компиляция; низкий порог входа | Менее выразительная система типов; сборщик мусора (некритично для сервера) |
| Java / Kotlin | Богатая экосистема, Spring Security, SAML | JVM в поставке, выше потребление памяти, сложнее air-gapped обновления |
| C# (.NET) | Сильная экосистема, хорошая интеграция с AD | Рантайм в поставке; на Linux-серверах экспертиза у эксплуатации обычно ниже |
| Rust | Единый язык с ядром | Дольше разработка CRUD-логики и интеграций; меньше зрелых библиотек SAML |

## Решение

Go. Версия тулчейна фиксируется в `go.mod` (директива `toolchain`). Минимальная версия — та, что поддерживается проектом Go на дату выпуска.

## Обоснование

Основная работа сервера — API, авторизация, интеграции и хранение. В этих задачах Go даёт лучшее соотношение скорости разработки и простоты эксплуатации. Риск ошибок памяти при разборе недоверенных данных снят тем, что такой разбор вынесен в Rust-ядро.

## Последствия

- Вызов Rust-ядра из сервера выполняется через отдельный процесс-воркер с ограничениями (seccomp, лимиты памяти и времени), а не через cgo в адресном пространстве сервера. Сбой парсера не роняет сервер.
- Обязательные проверки в CI: `go vet`, `staticcheck`, `govulncheck`, `gofmt`.

## Риски

| Риск | Мера |
| --- | --- |
| Зрелость SAML-библиотек на Go | Проверка выбранной библиотеки перед реализацией DLP-INTEGRATION-004; OIDC — основной путь SSO |
| Накладные расходы межпроцессного вызова ядра | Пакетная обработка, замер на пилоте |
