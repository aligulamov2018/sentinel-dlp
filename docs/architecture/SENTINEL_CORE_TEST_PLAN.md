## 1. Уровни и среда

| Уровень | Что проверяет | Среда |
| --- | --- | --- |
| Unit | Определение типа, извлечение, нормализация, детекторы, валидаторы, PDP | Linux CI; Windows CI — по решению S-05 |
| Contract | Схемы `InspectionResult`, `Decision`, `ExtractedContent`, вывод CLI; совместимость версий | CI |
| Golden | Детерминизм: канонический `Decision` и вывод CLI побайтно | CI на двух ОС, с разным числом потоков |
| Property-based | Инварианты INV-C1…C7, INV-C10…C14 на сгенерированных политиках и результатах инспекции; эталон — полный перебор фактических количеств и классов в модели независимых счётчиков; отдельно — корпус со связанными детекторами (TC-CORE-39) | CI |
| Fuzz | Парсеры, загрузчик бандла, декодер `ExtractedContent` | Изолированные исполнители |
| Fault injection | Паника, исчерпание бюджета, отмена, ошибки чтения | CI |
| Performance | Задержка этапов и пик памяти на 1, 10 и 100 МБ | Эталонное оборудование |
| Static | Граф зависимостей crates, запрет `unsafe`, `cargo audit`, `cargo deny` | CI |

Корпуса — только синтетические данные (`sentinel-core-testkit`): размеченный корпус для precision и recall, корпус обхода, вредоносный корпус. Вредоносный корпус запускается только в изолированной среде.
