# Sentinel DLP — Changelog

### Проверка

Выполнена сверка на момент создания: уникальность идентификаторов, однозначное соответствие `DLP-*` и `FR-*`, наличие обязательных полей карточек, существование зависимостей, отсутствие зависимости от функции более позднего релиза, разрешимость относительных ссылок и якорей между документами, корректность ссылок на `ADR-*`, `RSK-*`, `PoC-*`, `OQ-*`. Сверка не заменяет содержательную рецензию.

Сведения о Windows сверены с Microsoft Learn 2026-11-09: группы и высоты minifilter, требования к подписи драйверов, Windows protected print mode и план окончания обслуживания сторонних драйверов печати, API буфера обмена.
